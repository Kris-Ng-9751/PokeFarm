# OSE Console 后台改动清单：好友 · 送礼物 · 排行榜（游戏 v334 起）

游戏这边已经做好。后台没改之前：

- 好友和排行榜照样能用。别人的称号、对战塔层数、本周紧急任务显示「—」，拜访牧场只看得到对方的对战阵容。
- 送礼物按钮会提示「后台还没开放送礼物」。

所有接口都和现在的 `players`、`shared`、`party` 一样：

- 地址：放在存档地址旁边，即把 `.../save` 换成 `.../<名字>`。
- 登录：用同一个登录 cookie（`credentials: 'same-origin'`）。
- 格式：请求和回应都是 JSON。

## 1. `GET players`：每一行多带一个 `pub`（必须）

游戏每次存档都会把公开资料写进存档的 `data.pub`。请原样放进 `players` 回应的每一行：

```js
row.pub = save.data.pub ?? null
```

`pub` 的内容（游戏写入，后台不用检查）：

| 栏位 | 意思 |
|---|---|
| `v` | 版本，现在是 1 |
| `title` / `titleN` | 佩戴的称号 id / 称号名字 |
| `tower` | 对战塔最高层 |
| `towerW` | `{k: 本周一日期, best: 本周最高层}` |
| `urgW` | `{k: 本周一日期, n: 本周完成的紧急任务数}`（`k` 不是本周的就当 0） |
| `urgT` | 紧急任务累计完成数 |
| `dex` / `shiny` | 图鉴捉到数 / 异色图鉴数 |
| `ranch` | 拜访时显示的牧场宝可梦，最多 10 只 `[{id, lv, s}]`（`s`=1 是异色） |
| `fr` | 好友数 |
| `farm` | `{n, max, soil}` 农场资料 |

`pub` 不到 2 KB。

## 2. 送礼物（必须，否则送礼物不能用）

### `POST gifts/send`

```json
{ "to": "<对方的 u>", "coins": 500, "items": { "berry": 1 }, "msg": "一起加油！" }
```

- `coins` 和 `items` 两者只有一个有值。`items` 最多 1 种、1 个。`msg` 最多 40 字。
- 后台存成一笔礼物：

  ```json
  { "id": "...", "from": "<我的 u>", "fromName": "<我的名字>", "to": "...", "coins": 0, "items": {}, "msg": "...", "t": 1731900000000 }
  ```

- 回应：
  - `200 {ok:true}`：成功。游戏收到 200 才会从送礼的人那里扣金币或道具。
  - `404`：`to` 不存在。
  - `429`：同一个人一天送超过 3 份（游戏这边也限制了，后台再挡一次）。

### `GET gifts`

回应：

```json
{ "gifts": [ { "id": "...", "from": "...", "fromName": "...", "coins": 0, "items": {}, "msg": "...", "t": 0 } ] }
```

- 只回给 `to` 是自己、而且还没领的礼物，按时间新到旧。
- 游戏收到 404 就当作后台还没开放送礼物。

### `POST gifts/claim`

```json
{ "id": "<礼物 id>" }
```

回应：

- `200`：成功。游戏收到 200 才把金币或道具加到领取人的存档。
- `409`：已经领过。
- `404`：不是给自己的，或者找不到这份礼物。

## 3. 拜访记录（可选，没有也能玩）

- `POST visits {to}`：每天第一次拜访一位好友时，游戏会送一次。后台记下 `{from, fromName, to, t}`，只保留最近 30 笔即可。
- `GET visits`：回应 `{visits:[{from, fromName, t}]}`，内容是最近来拜访自己的人。游戏会显示在「好友 → 收到的礼物」下面。收到 404 就不显示。

## 不需要后台的部分

以下都在存档里，不用后台：

- 对战塔
- 称号
- 好友名单（`S.social.fr`）
- 拜访金币
- 每日送礼次数
