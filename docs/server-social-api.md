# OSE Console 后台改动清单：排行榜（游戏 v334 起，v379 更新）

游戏这边已经做好。后台没改之前，排行榜照样能用，别人的称号、对战塔层数、本周紧急任务显示「—」。

好友、拜访牧场、送礼物在 v379 已经拿掉，之前清单里的 `gifts`、`visits` 接口不用再做。

接口和现在的 `players` 一样：

- 地址：放在存档地址旁边，即把 `.../save` 换成 `.../players`。
- 登录：用同一个登录 cookie（`credentials: 'same-origin'`）。
- 格式：JSON。

## `GET players`：每一行多带一个 `pub`（必须）

游戏每次存档都会把公开资料写进存档的 `data.pub`。请原样放进 `players` 回应的每一行：

```js
row.pub = save.data.pub ?? null
```

`pub` 的内容（游戏写入，后台不用检查）：

| 栏位 | 意思 |
|---|---|
| `v` | 版本，现在是 1 |
| `title` / `titleN` | 佩戴的称号 id / 称号名字 |
| `tower` | 对战塔最高层 |
| `towerW` | `{k: 本周一日期, best: 本周最高层}` |
| `urgW` | `{k: 本周一日期, n: 本周完成的紧急任务数}`（`k` 不是本周的就当 0） |
| `urgT` | 紧急任务累计完成数 |
| `dex` / `shiny` | 图鉴捉到数 / 异色图鉴数 |
| `farm` | `{n, max, soil}` 农场资料 |

`pub` 不到 1 KB。
